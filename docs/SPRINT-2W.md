## 2. Scope ที่ปรับให้พอดีกับ 2 สัปดาห์

| เรื่อง | PROJECT-PLAN | ใช้จริง |
|---|---|---|
| จังหวัด | 8 จังหวัด | **กรุงเทพฯ + ชลบุรี** (ชลบุรีครอบคลุมพัทยา บางแสน และศรีราชา) |
| Origin | หลายเมือง | **กรุงเทพฯ หรือ ชลบุรี** ใช้ได้ครบ 4 แบบ ได้แก่ กทม→กทม, กทม→ชลบุรี, ชลบุรี→กทม และ ชลบุรี→ชลบุรี |
| ต้นทางและปลายทางเป็นจังหวัดเดียวกัน | – | **ฟอร์มซ่อนขั้น "วิธีเดินทางข้ามเมือง"** และให้ค่าเดินทางข้ามเมืองเป็น 0 |
| วิธีเดินทางข้ามเมือง | รถ / รถไฟ / เครื่องบิน / ขับเอง | **รถทัวร์/รถตู้ · รถไฟ · ขับรถเอง** (ไม่มีเครื่องบิน) |
| Place ต่อจังหวัด | 30 / 30 / 15 | **Attraction 25 · Restaurant 20 · Accommodation 8** เป็นจำนวนขั้นต่ำ และเพิ่มได้ภายหลังโดยไม่ต้องแก้โค้ด |
| เก็บข้อมูล Place | Seed จาก Places API ลง Firestore | **ไฟล์ JSON ใน `assets/data/`** ([ADR-0002](./adr/0002-bundle-place-data-as-assets.md)) |
| Firestore | provinces / places / trips / users | **trips / users เท่านั้น** |
| Gemini ① ตีความ Free-text Note | เรียก Gemini แยกอีกครั้ง | **ใส่ข้อความลงใน prompt ③ และ ⑥ โดยตรง** |
| Night Stay | แยกที่พักได้ถ้าไกลเกิน 40 กม. | **พักที่เดียวทั้งทริป** |
| เวลาเปิด-ปิด | สลับลำดับหรือตัด Stop | **แสดงคำเตือนอย่างเดียว** |
| แผนที่ | Google Maps SDK + Routes API | **`flutter_map` + OpenStreetMap และวาดเส้นตรงเชื่อมหมุด** ([ADR-0003](./adr/0003-openstreetmap-instead-of-google-maps.md)) |
| ดีไซน์ | – | **Material 3 เท่านั้น** ทั้ง Android และ iOS ดู [DESIGN.md](./DESIGN.md) |

### สถานการณ์สำหรับ Demo (ใช้เป็นชุดทดสอบใน M4 ด้วย)

1. **หลัก:** "เสาร์–อาทิตย์ 2 วัน 1 คืน งบ 6,000 บาท 2 คน ออกจากกรุงเทพฯ ชอบทะเลกับคาเฟ่ เที่ยวแบบชิล" → ระบบเสนอชลบุรีก่อนกรุงเทพฯ → ได้แผนพัทยา–บางแสนพร้อมแผนที่
2. **เที่ยวในจังหวัด:** "เที่ยวในกรุงเทพฯ 1 วัน งบ 1,500 บาท 1 คน สายวัดกับประวัติศาสตร์" → ไม่มีขั้นวิธีเดินทางข้ามเมือง และค่าเดินทางข้ามเมือง = 0
3. **เกินงบ:** "ชลบุรี 3 วัน 2 คืน งบ 3,000 บาท 4 คน" → แสดง Over Budget พร้อมคำแนะนำ 2–3 ข้อ
