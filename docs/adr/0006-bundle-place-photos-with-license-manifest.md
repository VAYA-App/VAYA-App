# รวมรูปถ่ายสถานที่ไว้ในแอปพร้อม manifest ลิขสิทธิ์

รูปของ Place และ Destination เก็บเป็นไฟล์ WebP ใน `assets/` (กว้าง 800px สำหรับการ์ด และสัดส่วน 16:9 สำหรับ hero) แล้วรวมไปกับแอปตอน build ไม่มีรูปที่โหลดจากเน็ต รูปทุกรูปต้องมีแหล่งที่มา ผู้ถ่าย และ license บันทึกไว้ใน manifest ซึ่งแอปอ่านไปแสดงในหน้า "เครดิตภาพ" รูปที่ license ไม่อนุญาตให้ใช้ในแอป หรือหาที่มาไม่ได้ ห้ามนำเข้า Place ไหนไม่มีรูปให้ใช้ภาพประจำหมวดแทน

เราเลือกแบบนี้เพื่อให้สอดคล้องกับ ADR 0002 คือข้อมูลสถานที่อยู่ในแอปและใช้ได้ตอนออฟไลน์ และตรวจลิขสิทธิ์ได้ผ่าน PR รูปที่เป็นสถานที่จริงเอามาจาก Wikimedia Commons (บาง license ต้องให้เครดิต) ส่วนรูปบรรยากาศใช้ Unsplash หรือ Pexels ข้อเสียคือแอปใหญ่ขึ้นราว 6–10 MB และเปลี่ยนรูปแล้วต้อง build ใหม่

## Considered Options

- โหลดรูปจาก URL ภายนอกตอนเปิดหน้า: ตัดทิ้งเพราะออฟไลน์แล้วไม่มีรูป ลิงก์อาจเสีย และควบคุมเครดิตไม่ได้
- Google Places Photos: ตัดทิ้งเพราะต้องผูกบัตรและห้ามเก็บรูปไว้นาน
