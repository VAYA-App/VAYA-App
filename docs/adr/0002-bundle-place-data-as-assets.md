# เก็บข้อมูลจังหวัดและสถานที่เป็นไฟล์ JSON ในแอป

ข้อมูล Province และ Place ทั้งหมดเก็บเป็นไฟล์ JSON ใน `assets/data/` แล้วรวมไปกับแอปตอน build ส่วน Firestore เก็บเฉพาะข้อมูลที่ผู้ใช้สร้าง คือ `trips` และ `users` ทีมกรอกข้อมูลสถานที่เอง โดยดูจาก Google Maps และแหล่งข้อมูลเปิด และการเพิ่มจังหวัดหรือสถานที่ทำได้โดยเพิ่มไฟล์และเพิ่มรายการใน `provinces.json` โดยไม่ต้องแก้โค้ด

เราเลือกแบบนี้เพราะมีเวลาแค่ 2 สัปดาห์ การเขียนสคริปต์ seed จาก Places API และนำข้อมูลเข้า Firestore ใช้เวลาเกือบหนึ่งวันโดยไม่ได้ฟีเจอร์ใหม่ เงื่อนไขของ Google Maps Platform ยังจำกัดการเก็บข้อมูล Places ไว้นาน และการอ่านไฟล์ในแอปทำให้ Planner Engine ทดสอบได้โดยไม่ต้องต่อเน็ต ข้อเสียคือแก้ข้อมูลแล้วต้อง build แอปใหม่ ซึ่งรับได้ในงานรอบนี้

## Considered Options

- Seed จาก Places API ลง Firestore ตามแผนเดิม: ตัดทิ้งเพราะใช้เวลามากและติดเงื่อนไขการเก็บข้อมูล
- กรอกข้อมูลลง Firestore Console โดยตรง: ตัดทิ้งเพราะไม่มี history ใน Git และรีวิวผ่าน PR ไม่ได้
