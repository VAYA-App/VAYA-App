## 2. ทางเลือกที่คำนวณ

ทุกข้อคิดราคาใหม่ด้วย `calculator.applyCosts` ตัวเดียวกับแผนจริง แล้ว `saving = ยอดรวมเดิม − ยอดรวมใหม่` ไม่ประมาณเอง และไม่เอายอดประหยัดของแต่ละข้อมาบวกกัน

| Kind | ทำอย่างไร | มีเมื่อ |
|---|---|---|
| `downgradeAccommodation` | แทนที่พักทุกคืนด้วยที่พักในจังหวัดเดียวกันที่ Price Level ต่ำกว่า (ระดับใกล้สุด แล้วเลือกแห่งที่ใกล้ที่พักเดิมสุด ใช้ `NightStayPlanner.pickAccommodation`) | แผนมีที่พัก และข้อมูลมีที่พักระดับต่ำกว่า |
| `changeLocalTransport` | ลองอีก 3 โหมด เอาโหมดที่ยอดรวมต่ำสุด | มีโหมดที่ถูกกว่าจริง |
| `removeDay` | ตัดวันสุดท้ายและคืนสุดท้ายออกจากแผน เลื่อน `endDate` เข้ามา 1 วัน แล้วคิดราคาใหม่ (ไม่รัน planner ซ้ำ) | แผนมี 2 วันขึ้นไป |
| `changeDestination` | เทียบ `minimumTripCost` ของจังหวัดอื่นกับของจังหวัดปัจจุบัน (ดู D1) ข้ามจังหวัดที่ `seasonality` ของเดือนเดินทางเป็น `avoid` | มีจังหวัดที่ค่าขั้นต่ำต่ำกว่า |

ผลลัพธ์: ตัดข้อที่ `saving <= 0` ออก เรียงตามยอดประหยัดมากไปน้อย โดยข้อที่เป็นขอบล่าง (`changeDestination`) อยู่ท้ายเสมอ แล้วคืนไม่เกิน 3 ข้อ · แผนที่ไม่เกินงบคืน list ว่าง

### ข้อความ (ภาษาไทย ใช้ "~" ทุกข้อเพราะเป็นราคาประมาณ)
- `เปลี่ยนที่พักเป็น <ชื่อ> (฿฿) ประหยัด ~฿3,000` · ต่อท้าย "แต่ไม่รวมอาหารเช้า" เมื่อที่พักเดิมรวมและที่ใหม่ไม่รวม
- `เปลี่ยนเป็นรถสาธารณะ ประหยัด ~฿4,101`
- `ลดเหลือ 2 วัน 1 คืน ประหยัด ~฿9,095` (ทริป 2 วันเขียน "ลดเหลือ 1 วัน ไม่ค้างคืน")
- `เที่ยว<จังหวัด>แทน เริ่มต้นถูกกว่า ~฿X`

## 3. เมื่อทำทุกข้อแล้วยังเกินงบ: `rescue`

คิดราคาแผนที่ใช้ทุกทางเลือกพร้อมกัน (ที่พักถูกลง + โหมดถูกสุด + ตัด 1 วัน) เป็นแผนเดียว ถ้ายังเกินงบคืน

```dart
final class BudgetRescue {
  final int stillOverBy;      // ยังเกินอีกเท่าไรหลังทำทุกข้อ
  final int minimumBudget;    // minimumTripCost ของคำขอนี้ ปัดขึ้นหลักร้อย
  final int? daysThatFit;     // จำนวนวันมากสุดที่ค่าขั้นต่ำไม่เกินงบ (null = ไม่มี)
  final int? costOfDaysThatFit;
}
```
ถ้าทำทุกข้อแล้วเข้างบ คืน `null` · อยู่ใน `lib/planner/` ไม่แตะ `lib/domain`

## 4. ตัวเลขจริงจาก pipeline (ข้อมูลตัวอย่างปัจจุบัน, เลือกสถานที่แบบ fallback)

**Demo 3: กทม→ชลบุรี 3 วัน 4 คน งบ 3,000 แท็กซี่** · แผน 22,370

| ทางเลือก | ยอดใหม่ | ประหยัด |
|---|---|---|
| ลดเหลือ 2 วัน | 13,275 | 9,095 |
| รถสาธารณะ | 18,269 | 4,101 |
| มอเตอร์ไซค์ / รถเช่า | 19,077 / 20,945 | 3,293 / 1,425 (ไม่แสดง เพราะแสดงแค่โหมดถูกสุด) |
| ลดระดับที่พัก | ไม่มี | ข้อมูลชลบุรีมีแค่ระดับ ฿฿฿ และ ฿฿฿฿ |
| เปลี่ยนจังหวัด | ไม่มี | ค่าขั้นต่ำ กทม. 6,248 สูงกว่าชลบุรี 6,081 |

→ คำแนะนำ 2 ข้อ (ผ่าน AC "≥ 2 ข้อ" พอดี)
→ `rescue`: ทำทั้งสองข้อพร้อมกันได้ 10,789 ยังเกิน 7,789 · ควรมีงบอย่างน้อย ฿6,100 · งบนี้พอสำหรับทริป 1 วัน (เริ่มต้น ~฿1,197)

**Demo 1: กทม→ชลบุรี 2 วัน 2 คน งบ 6,000 แท็กซี่** · แผน 8,916 (เกินงบ ทั้งที่ #32 คาดว่าอยู่ในงบ)
→ ลดเหลือ 1 วัน ประหยัด 5,223 · รถสาธารณะ ประหยัด 2,400 · `rescue` = null (ทำทั้งสองข้อได้ 1,742)

ตัวเลขเหล่านี้จะเปลี่ยนเมื่อ #20–#22 เติมข้อมูล test จึงไม่ผูกกับเลขตายตัว (ดูข้อ 7)
